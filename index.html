Before you collect:

This diagnostic page sends technical information to its own /api/raw endpoint, including browser capabilities, display details, network hints, page-performance metrics, request metadata, your public IP address and approximate IP-based location. Precise device location is separate and is only requested when you press the location button and approve the browser prompt. The API code returns the data but does not save it to a database.
